# FileUpload

Drag-and-drop or click-to-select file input with thumbnail preview. Built with native browser APIs — no external dependencies.

## Usage

```tsx
import { FileUpload } from '@awakr/awake-ui/file-upload';

<FileUpload.Root multiple onChange={(files) => console.log(files)}>
  <FileUpload.Dropzone />
  <FileUpload.FileList />
</FileUpload.Root>
```

## Customizing accepted types

The `accept` prop takes an array of MIME types. The default accepts common image formats.

```tsx
// Images only (default)
<FileUpload.Root accept={['image/jpeg', 'image/png', 'image/webp']}>

// Future: extend to other types
<FileUpload.Root accept={['application/pdf', 'text/plain']}>
```

# Loading

Component for displaying a loading indicator with animated dots.

```tsx
import { Loading } from '@developmentsnil/awake-ui/loading';
import '@developmentsnil/awake-ui/style.css';
```

## Basic Usage

```tsx
<Loading />
<Loading size="sm" />
<Loading size="md" />
<Loading size="lg" />
```

<Canvas of={LoadingStories.Default} />

## Sizes

<Canvas of={LoadingStories.Sizes} />

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size of the loading indicator |

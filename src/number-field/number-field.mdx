# NumberField

Input numérico com botões de incremento/decremento, validação de limites e suporte a scrub. Baseado no Base UI NumberField.

```tsx
import { NumberField } from '@developmentsnil/awake-ui/number-field';
import '@developmentsnil/awake-ui/style.css';
```

## Usage

```tsx
import { NumberField } from '@developmentsnil/awake-ui/number-field';

<NumberField.Root
  defaultValue={1}
  min={0}
  max={99}
  step={1}
  onValueChange={(value) => console.log(value)}
>
  <NumberField.Group>
    <NumberField.Decrement>−</NumberField.Decrement>
    <NumberField.Input />
    <NumberField.Increment>+</NumberField.Increment>
  </NumberField.Group>
</NumberField.Root>
```

## API

### `NumberField.Root`

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `number` | — | Controlled value |
| `defaultValue` | `number` | — | Uncontrolled initial value |
| `onValueChange` | `(value: number) => void` | — | Called on every change |
| `min` | `number` | — | Minimum allowed value |
| `max` | `number` | — | Maximum allowed value |
| `step` | `number` | `1` | Step for buttons and arrow keys |
| `largeStep` | `number` | `10` | Step for Page Up/Down keys |
| `disabled` | `boolean` | `false` | Disables the field |
| `readOnly` | `boolean` | `false` | Makes the field read-only |
| `allowWheelScrub` | `boolean` | `false` | Enables mouse wheel scrubbing |

### `NumberField.ScrubArea`

| Prop | Type | Default | Description |
|---|---|---|---|
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | Drag direction |
| `pixelSensitivity` | `number` | `2` | Pixels per value change |

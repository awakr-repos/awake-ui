# VirtualList

Renders large lists efficiently by only mounting the rows visible in the viewport.
Built on `@tanstack/react-virtual`.

Use `VirtualList` when the list is long (hundreds or thousands of items) and performance matters.

## Default

<Canvas of={Stories.Default} />
<Controls of={Stories.Default} />

## Usage

```tsx
import { VirtualList } from '@awakr/awake-ui/virtual-list';

const ITEMS = Array.from({ length: 5000 }, (_, i) => ({ id: i + 1, name: `Item ${i + 1}` }));

<VirtualList
  items={ITEMS}
  itemHeight={48}
  height={400}
  renderItem={(item) => <span>{item.name}</span>}
/>
```
